이 프로젝트에 맞는 프론트엔드 구현 명세서를 작성해 주세요.

### 작성 목표
- React + Vite 기반으로 구현할 채팅 UI의 전체 구조를 명확히 정의한다.
- FastAPI 백엔드와의 API 연동 방식, 데이터 흐름, UI 상태 관리 방식까지 포함한다.
- 초보자도 이해하기 쉽고, 유지보수하기 쉬운 코드 구조를 고려한다.
- UI/UX 관점에서 사용자 경험이 좋도록 구성되는지까지 반영한다.

### 출력 파일명
- frontend/docs/frontend_spec.md

### 포함해야 할 내용
1. 구현 목적
2. 구현 범위
3. 화면 구성 개요
4. 기능 요구사항
   - 기본 채팅 기능
   - 모델 선택 기능
   - 시스템 프롬프트 설정 기능
   - 파라미터 조정 기능
   - 로딩/에러 상태 처리
   - 대화 관리 기능
5. API 연동 규격
   - /chat 요청/응답 형식
   - /models 응답 형식
   - 에러 처리 방식
6. 데이터 구조
   - 메시지 객체
   - 대화 객체
   - 설정 상태 객체
7. 컴포넌트 구조
   - 컴포넌트 역할 분리
   - 스타일 관리 방식
8. UI/UX 구현 가이드
   - 레이아웃 방향
   - 접근성 고려사항
   - 초보자 친화적 UX
9. 구현 순서
10. 완료 기준
11. 구현 시 주의사항

### 코드 작성 원칙
- 초보자도 이해하기 쉽게 작성한다.
- 코드 구조는 clean하고 유지보수 가능하게 구성한다.
- 실제 구현 시 오류가 나지 않도록 사양을 꼼꼼하게 검토한다.
- 프론트엔드와 백엔드의 연동 포인트를 명확하게 명시한다.

### 라이브러리/프레임워크 문서 확인 지침
다음 기술을 사용할 때는 반드시 Context7 MCP를 사용해 최신 공식 문서와 코드 예제를 참고한 뒤 구현 방향을 정리해 주세요.
- FastAPI
- React
- Vite
- Ollama

### 추가 지시
- 설계도 이미지의 화면 구성 요소를 반영하여 UI 구조를 구체적으로 제시한다.
- 컴포넌트별 책임 분리를 명확히 하며, 공통 스타일과 전역 스타일은 별도로 관리하는 방식도 포함한다.
- 가능하면 실제 구현에 바로 이어질 수 있는 구체적인 디렉터리 구조와 파일 구조까지 포함한다.

## 결과물 예시의 방향
생성되는 명세서는 다음 성격을 갖도록 해 주세요.
- 개발자가 바로 구현에 들어갈 수 있을 정도로 구체적일 것
- 백엔드 API와 연결되는 지점을 명확히 포함할 것
- UI/UX를 고려한 사용자 경험 개선 포인트가 반영될 것
- 초보자도 이해하기 쉬운 설명과 예시 코드 구조를 포함할 것
