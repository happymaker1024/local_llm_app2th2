# frontend_spec.md

## 1. 목적
이 문서는 FastAPI 기반 로컬 LLM 백엔드와 연동되는 React + Vite 채팅 UI를 구현하기 위한 프론트엔드 사양서이다.  
목표는 사용자가 자연스럽게 채팅을 주고받고, 모델/프롬프트/파라미터를 조정할 수 있는 단일 페이지 애플리케이션을 만드는 것이다.

---

## 2. 구현 범위
- React 19 + Vite 기반의 채팅 UI 구현
- FastAPI 백엔드의 /chat, /models API 연동
- UI/UX를 기반으로 사용자 경험이 좋고 직관적인 인터페이스 구성
- 유지보수성을 고려한 컴포넌트 분리
- 오류 발생 시 사용자에게 명확한 안내 제공

## 4. 기능 요구사항

### 4.1 기본 채팅 기능
- 사용자가 메시지를 입력하면 백엔드 /chat API로 전송한다.
- AI 응답을 화면에 표시한다.
- 응답은 사용자 메시지와 AI 메시지의 순서로 채팅 목록에 추가된다.
- 한 번에 하나의 메시지 요청을 처리한다.

### 4.2 모델 선택 기능
- 초기 로딩 시 /models API를 호출해 사용 가능한 모델 목록을 가져온다.
- 드롭다운으로 모델을 선택할 수 있다.
- 선택된 모델은 다음 요청부터 적용된다.

### 4.3 시스템 프롬프트 설정 기능
- 사용자가 시스템 프롬프트를 입력할 수 있다.
- 기본값은 백엔드 스키마에 정의된 값으로 초기화한다.
- 필요 시 설정 패널에서 수정 가능하도록 한다.

### 4.4 파라미터 조정 기능
다음 값은 선택적으로 조정 가능해야 한다.
- temperature
- top_p
- num_predict

입력 방식은 간단한 숫자 입력 또는 슬라이더 형태로 구현 가능하다.  
초보자 친화성을 위해 기본값을 미리 보여주고, 범위를 명확하게 안내한다.

### 4.5 상태 표시 기능
다음 상태를 UI에 명확히 표시한다.
- 로딩 중: "응답 생성 중..."
- 성공: 메시지 출력
- 실패: 에러 메시지 출력

### 4.6 대화 관리 기능
- 새 대화 시작 버튼 제공
- 대화 목록 클릭 시 해당 대화로 전환 가능
- 현재 대화는 메모리 상태로 유지하되, 기본 구현에서는 세션 단위로 관리한다.

## 5. API 연동 규격

### 5.1 모델 목록 조회
- Endpoint: GET /models
- 응답 예시:

```json
{
  "models": [
    "exaone3.5:7.8b",
    "llama3.2:3b"
  ]
}
```

### 5.2 채팅 요청
- Endpoint: POST /chat
- 요청 본문:

```json
{
  "message": "사용자 입력 메시지",
  "model": "exaone3.5:7.8b",
  "system_prompt": "너는 초보자를 돕는 친절한 AI 강사다.",
  "temperature": 0.5,
  "top_p": 0.9,
  "num_predict": 512
}
```

- 응답 본문:

```json
{
  "model": "exaone3.5:7.8b",
  "message": "AI 응답 텍스트",
  "elapsed_time": 1.234
}
```

### 5.3 에러 처리
- 네트워크 오류 또는 서버 오류 발생 시 사용자에게 아래 형식으로 안내한다.
  - "응답을 받아오지 못했습니다. 잠시 후 다시 시도해주세요."
- 입력값이 비어 있으면 전송을 막고 안내 메시지를 표시한다.

## 6. 컴포넌트 구조
추천 구현 구조는 아래와 같다.

```text
src/
  App.jsx
  main.jsx
  api/
    chatApi.js
  components/
    ChatPage.jsx
    Sidebar.jsx
    ChatHeader.jsx
    MessageList.jsx
    MessageBubble.jsx
    ChatComposer.jsx
    SettingsPanel.jsx
  styles/
    chat.css
```

### 6.1 컴포넌트 역할
- App.jsx: 앱 진입점, 전역 상태 연결
- ChatPage.jsx: 전체 채팅 화면 조립
- Sidebar.jsx: 대화 목록 표시
- ChatHeader.jsx: 상단 제목 및 모델 선택 UI
- MessageList.jsx: 메시지 목록 렌더링
- MessageBubble.jsx: 사용자/AI 메시지 스타일 처리
- ChatComposer.jsx: 입력창 및 전송 버튼
- SettingsPanel.jsx: 시스템 프롬프트/파라미터 설정
- chatApi.js: 백엔드 API 호출 함수 모음

### 6.2 스타일 관리 원칙
- 컴포넌트별 CSS 작성은 유지보수와 가독성 측면에서 좋은 방식이다.
- 다만 공통 스타일(예: 버튼, 입력창, 레이아웃, 색상, 폰트)과 전역 스타일은 별도 파일로 분리하여 관리한다.
- 각 컴포넌트는 자신의 고유 스타일만 담당하고, 공통 스타일은 재사용 가능한 형태로 구성한다.
- 예시 구조는 아래와 같이 구성한다.

```text
src/
  styles/
    global.css
    variables.css
    layout.css
    components/
      ChatComposer.css
      MessageBubble.css
      Sidebar.css
```

## 7. UI/UX 구현 가이드

### 7.1 스타일 방향
- 깔끔하고 단순한 채팅 앱 느낌
- 사용자 메시지는 우측 정렬, AI 메시지는 좌측 정렬
- 입력창은 하단 고정형으로 구성
- 모바일/태블릿에서도 자연스럽게 보이도록 반응형 레이아웃 적용

### 7.2 접근성
- 버튼에 적절한 라벨 제공
- 키보드로 전송 가능하도록 구현
- 에러 메시지는 시각적으로 강조
- 색 대비를 충분히 확보

### 7.3 디자인 가이드
- 애플의 수석 디자이너가 디자인한 스타일로 한다.

## 9. 완료 기준
다음 조건을 모두 만족하면 구현 완료로 판단한다.
- 사용자가 메시지를 입력해 AI 응답을 받을 수 있다.
- 모델 목록을 불러와 선택할 수 있다.
- 시스템 프롬프트와 파라미터를 조정할 수 있다.

## 10. 구현 시 주의사항
- React 상태 관리는 컴포넌트가 지나치게 복잡해지지 않도록 분리한다.
- API 호출 함수는 별도 파일로 분리해 재사용 가능하게 만든다.
- 백엔드 응답 형식이 바뀌더라도 프론트는 최소한의 수정으로 대응할 수 있도록 설계한다.
- 초보자도 이해할 수 있도록 변수명과 함수명을 명확하게 작성한다.
- 코드 중복을 줄이고, 읽기 쉬운 구조로 구성한다.
